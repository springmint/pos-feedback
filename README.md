# POS 需求与反馈

这里统一收集和跟踪 POS 产品的客户需求、功能改进建议和使用问题。客户和团队成员都可以通过 GitHub Issues 提交反馈、补充信息和查看处理进展。

## 提交反馈

1. 先在 [Issues 列表](https://github.com/springmint/pos-feedback/issues?q=is%3Aissue) 搜索相似内容（包括已关闭的 Issue）。已有同一问题或需求时，直接评论补充你的场景或影响。
2. 打开 [新建 Issue](https://github.com/springmint/pos-feedback/issues/new/choose)，选择对应表单。每个 Issue 记录一件事，标题写清涉及的功能和具体诉求或现象。

| 表单 | 什么时候用 | 需要写清楚 |
| --- | --- | --- |
| 需求与改进 | 希望新增功能、简化操作或改善现有体验 | 谁在什么场景遇到什么困难，以及希望达到什么结果 |
| 问题反馈 | 已有功能出现报错、结果异常或流程中断 | 实际表现、如何复现和预期结果 |

例如，「交班时报表重复计入已退款订单」适合用「问题反馈」，「交班报表支持按支付方式汇总」适合用「需求与改进」。

**Issue、评论和附件均公开可见。** 发布前请移除客户姓名、联系方式、完整订单号、支付信息和凭据。门店收银中断或需要核对具体交易时，请及时联系你平时对接的 POS 支持人员。

## 跟进处理进展

团队在原 Issue 中确认影响、补充所需信息并记录处理结论。已发布的改动或修复会补充适用版本或生效时间，合并跟踪的反馈会链接到对应的 Issue。你可以订阅原 Issue 接收更新。
